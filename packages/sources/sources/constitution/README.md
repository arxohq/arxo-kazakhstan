# Закрепление Конституций Республики Казахстан

Дата получения: **2026-08-26**. Байты получены вручную; сборка и CI к сети
не обращаются (DECISION-0005 п. 6).

## Конституция 2026 года

Первичный источник — официальный сайт Президента Республики Казахстан:

- ru: `https://mirror.akorda.kz/ru/konstituciya-respubliki-kazahstan-3053339`;
- kk: `https://mirror.akorda.kz/kz/konstituciya-respubliki-kazahstan-3053339`.

`constitution-2026-*.html` — полученные HTML-байты. Файлы
`constitution-2026-*.txt` воспроизводимо получены из них скриптом
`corpus/tools/lib/extract_source_text.py`; два запуска для каждого языка дали
байтово одинаковый результат (`cmp` exit 0). В каждой редакции найдено ровно
96 последовательных заголовков статей 1–96.

Adilet был повторно проверен 26.08.2026: страницы
`https://adilet.zan.kz/{rus,kaz}/docs/K2600000000` отвечают HTTP 200 с
валидной TLS-цепочкой. Akorda оставлен первичным источником согласно
`spec/KZ-CONSTITUTION-AUDIT.ru.md`; Adilet использован как независимый
контроль доступности и метаданных официального опубликования.

## Конституция 1995 года

Текущая утратившая силу консолидированная редакция закреплена с Adilet:

- ru: `https://adilet.zan.kz/rus/docs/K950001000_`;
- kk: `https://adilet.zan.kz/kaz/docs/K950001000_`.

Закреплённая консолидация содержит номера 1–99 и три вставленные статьи
83-1, 94-1, 94-2 — всего 102 заголовка. Это не исправляется по памяти о
первоначальном тексте 1995 года: source model описывает именно официальную
консолидацию на дату получения, прекратившую действие 01.07.2026.

**Перезакрепление 27.08.2026 — снят редакционный аппарат Adilet.** Страницы
Adilet несут ВНУТРИ статей два вида аппарата портала: примечания
Конституционного Суда (красный шрифт; `Примечание.` / `Ескертпе.` — 89 и 87
блоков) и историю изменений (`class="note"`; `Сноска.` / `Ескерту.` — по 65).
В 80 статьях из 85 аппарат стоит МЕЖДУ абзацами, поэтому текст статьи без него
переставал быть непрерывной подстрокой публикации, а DECISION-0005 п. 5
требует именно вхождения (`LDC-E5202`). Фрагменты 1995 нельзя было завести ни
с аппаратом (он попал бы в `content_hash` §194 наравне с нормой), ни без него.

`extract_source_text.py` научен снимать аппарат ДО закрепления байтов, и только
при совпадении сигнатуры: сама разметка основанием не является, неопознанный
блок остаётся в тексте — страница, пометившая тем же способом изменённую
норму, иначе потеряла бы право молча. Проверено построчно: из русской редакции
ушли 154 строки, ВСЕ 154 — аппарат, добавленных строк нет. Регрессия на
четырёх ранее закреплённых текстах (обе редакции 2026, Алаш, Независимость) —
байтово без сдвига; повторный запуск на том же HTML даёт идентичные байты.
HTML не перезакреплялся: он остаётся как получен, изменено только
воспроизводимое извлечение.

С этого перезакрепления обе редакции 1995 несут постатейный слой: 102 статьи ×
2 языка.

**Уровень §33.1 у редакции 1995 — НЕ `SOURCE_ONLY`.** Здесь до 12.09.2026
стояло обратное: «уровень у всех — `SOURCE_ONLY`… не заявка на формализацию».
Утверждение перестало быть верным вместе с ростом слоя 1995 и осталось в
тексте: аудит `docs/audits/2026-09-12/KZ-CONSTITUTION-GRAMMAR-AUDIT.ru.md` измерил
**EXECUTABLE 82 / ANCHORED 19 / SOURCE_ONLY 1** из 102 единиц, то есть на
редакцию 1995 заякорены 268 правил из 631. Ложная объявленная граница — тот же
класс, что неверный `despite` в `check_source_pinning.py`, только объявляет её
проза README, и проверять её некому.

Мера снимается не одним аргументом `boundaries.py`: он выбирает редакцию 2026
как основную (у неё своя строка храповика `formalization-depth.json`). Для
редакции 1995 зовите `boundaries.depth()` напрямую, передав ей
`constitution-1995-ru.txt` и все девять CLIR семьи — рецепт с командой стоит в
разделе «Меры» отчёта аудита.

Единственная объявленная граница редакции 1995 — ст. 84, исключённая Законом
от 21.05.2007: она записана в `articles.json` с причиной и полем `despite`, и
её проверяет `check_source_pinning.py`. Она же даёт единственный `SOURCE_ONLY`.
